# TaskManager

**TaskManager** — десктопное приложение для управления задачами, проектами и рабочими досками. Разработано с использованием архитектуры клиент-сервер, где серверная часть предоставляет REST API, а клиентское приложение построено на WPF с MVVM-паттерном.

## ✨ Возможности

### Управление проектами
- Создание, редактирование и удаление проектов
- Назначение пользователей на проекты
- Просмотр досок проекта
- Фильтрация проектов по ролям пользователей

### Управление досками (Kanban)
- Создание досок с настраиваемыми колонками
- Drag-and-drop задач между колонками
- Приватные и публичные доски
- Визуальное отображение статуса задач

### Управление задачами
- Создание задач с указанием исполнителя
- Отслеживание дат начала и окончания
- Изменение статуса перетаскиванием между колонками
- Просмотр назначенных задач

### Управление пользователями
- Добавление и редактирование пользователей
- Импорт пользователей из Excel
- Назначение ролей (Admin, Editor, User)
- Просмотр профиля и контактной информации

## 🛠 Стек технологий

### Backend
- **Фреймворк:** ASP.NET Core 9.0 (Web API)
- **ORM:** Entity Framework Core 9.0
- **База данных:** SQL Server
- **Аутентификация:** JWT Bearer Tokens
- **Дизайн:** RESTful API
- **Паттерны:** Service Layer, Repository, DTO, Template Method

### Frontend
- **Фреймворк:** WPF (.NET 9.0)
- **Паттерн:** MVVM (Model-View-ViewModel)
- **Библиотеки:**
  - Prism (навигация, команды)
  - Newtonsoft.Json (сериализация)
  - EPPlus (работа с Excel)

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <https://github.com/tonyetotony/TaskManager.git>
cd TaskManager
```

### 2. Настройка базы данных

Откройте файл `TaskManager.Api/appsettings.json` и укажите строку подключения к вашей базе данных:

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=localhost;Database=TaskManagerDb;Trusted_Connection=True;TrustServerCertificate=True;"
  }
}
```

### 3. Создание базы данных

```bash
cd TaskManager.Api
dotnet ef database update
```

### 4. Запуск сервера

```bash
cd TaskManager.Api
dotnet run
```

Сервер запустится на `http://localhost:5139`

### 5. Запуск клиента

В отдельном терминале:

```bash
cd TaskManager.Client
dotnet run
```

## 🔑 Аутентификация

### JWT-токены

- Токен действует **30 минут**
- Автоматическая авторизация через Bearer-токен
- Кэширование учётных данных (опционально)

### Вход в систему

1. Введите логин и пароль
2. Выберите "Запомнить меня" (опционально)
3. После успешной авторизации откроется главное окно

### Начальный пользователь

При первом запуске автоматически создаётся администратор:
- **Логин:** `admin`
- **Пароль:** `qwerty123`
