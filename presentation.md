## Слайд 2. Актуальность

**Проблема:**
- Малые команды не используют дорогие системы управления задачами (Jira, Trello)
- Существующие решения перегружены функционалом для простых задач
- Нет лёгких open-source решений с Kanban-досками

**Решение:**
Разработать простое и понятное приложение для управления задачами с визуализацией рабочего процесса.

## Слайд 12. Аутентификация

**JWT-токены:**
- Генерация при входе
- Действует 2 минуты
- Автоматическая авторизация через Bearer-токен
- Хэширование паролей

**Процесс входа:**
```
Клиент → POST /api/account/token {login, password}
       → Сервер проверяет учётные данные
       → Сервер генерирует JWT-токен
       → Клиент сохраняет токен
       → Клиент отправляет токен с каждым запросом
```
